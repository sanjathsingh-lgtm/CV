# Sanjath Singh - Portfolio

A modern, responsive portfolio website showcasing AI, Data & Analytics Engineering expertise.

## Features
- Dark/Light theme toggle
- Responsive design with Tailwind CSS
- Interactive project showcase with modal details
- Animated sections with AOS (Animate On Scroll)
- LinkedIn integration
- Smooth scroll navigation

## Stack
- HTML5
- TailwindCSS
- Lucide Icons
- AOS (Animate On Scroll)
- Vanilla JavaScript

## Getting Started

1. Clone the repository
2. Open `sanjath-singh-portfolio.html` in a browser

## Hosting

Deploy to:
- GitHub Pages

- Netlify
- Any static hosting service
